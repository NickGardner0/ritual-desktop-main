
## Canonical App Paths

- `apps/dashboard`: Next.js dashboard app code
- `apps/backend`: FastAPI backend service
- `apps/desktop`: Tauri desktop shell (`src-tauri`, icon assets)
- `apps/browser-extension`: Chrome extension
- `apps/ios-companion`: iOS companion app
- `apps/tinybird`: Tinybird datasources, pipes, and support scripts

Shared libraries live in `packages/*`.
