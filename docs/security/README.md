# Ritual Security Documents

This folder contains the concise security documents most useful for vendor reviews and platform questionnaires.

Recommended upload order for Plaid:

1. `plaid-security-package.pdf`
2. `information-security-policy.md`
3. `incident-response-plan.md`
4. `access-control-policy.md`

Supporting source files:

- `plaid-security-package.md`
- `plaid-security-package.html`

If Plaid only asks for one document, upload `plaid-security-package.pdf` or `information-security-policy.md`.

Before submitting externally, optionally customize:

- security contact email
- legal entity name if different from Ritual
- signature block if you want a formally signed PDF
