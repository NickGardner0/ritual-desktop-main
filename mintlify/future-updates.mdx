## Principles for New Features

Every new feature in Ritual is evaluated against the same criteria:

1. **Does it make the daily review faster or more useful?**
2. **Does it reduce friction for logging?**
3. **Does it help you understand your life better over time?**

If it doesn't pass all three, it doesn't ship.
