Ritual is in active development. Here's what's on the roadmap, roughly in priority order.

## In progress

| Feature | Description |
|---------|--------------|
| Oura Ring integration | Full sleep stage data, HRV, readiness score, and temperature deviation synced automatically. |
| Apple Screen Time API | Direct integration for weekly app usage and phone pickup data — no screenshot needed. |
| Weekly digest | Auto-generated weekly summary delivered in the app every Monday morning, combining habits, wearable trends, and computer activity. |
| Google Calendar context | Attach calendar events as context to your habit logs so you can see how busy weeks affect your habits. |

## Planned

| Feature | Description |
|---------|--------------|
| Fitbit integration | Steps, active minutes, sleep data |
| Garmin integration | Workout sessions, VO2 max, training load |
| Richer pattern summaries | Cross-habit correlation analysis surfaced proactively |
| Import workflows | Faster bulk import from CSV and other app exports |
| Habit templates | Curated starting sets for common tracking goals |
