## Planned

| Feature | Description |
|--------|-------------|
| Apple Screen Time (iPhone) | Hourly, daily, weekly, and monthly app usage and statistics synced from iOS. |
| Controlled Experiments | Run behavioral experiments and use the app as an N=1 research tool with control/treatment periods and statistical analysis. |
| Life Timeline | Unified timeline of your life, with the ability to scrub through your history across all data sources. |
| Simulations | Predict outcomes based on extensive behavioral data. |
| Google Calendar | Two-way calendar sync for planning and schedule tracking. |
| Fitbit | Full OAuth integration for Fitbit wearable data (currently import-only). |

## Recently shipped

| Feature | Description |
|--------|-------------|
| AI Chat with tool-calling | Conversational AI with 16+ structured tool calls for querying habits, trends, correlations, anomalies, and activity data. |
| Voice mode | Native macOS speech recognition with real-time waveform visualization, contextual vocabulary hints, and streaming transcription. |
| Tesla integration | OAuth-connected Tesla vehicle tracking with automatic miles-driven habit logging via the Fleet API. |
| Plaid spending tracking | Bank account connectivity for daily spending behavior tracking projected into a managed habit. |
| Analytics dashboard | Draggable metric cards with streaks, trends, percent-change indicators, and correlation analysis. |
| Cloud memory | Optional cloud-backed semantic search over desktop activity and screen content with hybrid retrieval. |
| Data import system | Multi-format bulk import (CSV, screenshots, Apple Health, Whoop, Oura, Garmin, Fitbit) with validation, conflict resolution, and undo. |
| SMS onboarding | Automated welcome SMS with vCard contact card on user signup via SendBlue. |
| Anomaly detection | Z-score-based statistical outlier detection across all tracked habits. |
