## Design principles for new features

Every new feature in Ritual is evaluated against three questions:

1. **Does it reduce friction for logging or reviewing?** If adding the feature makes the daily review slower or more cluttered, it doesn't ship.
2. **Does it make patterns more visible over time?** Features that help you understand trends over weeks and months get prioritized over real-time dashboards.
3. **Does it work passively?** The best data is data you don't have to think about capturing.
