<Update label="June 2026" description="Desktop activity, iPhone Time, and canonical metrics" tags={["Desktop", "Metrics", "Integrations"]}>

### What’s new

- **Computer Time reliability** — Desktop activity tracking now has a stronger local fallback path and better watcher crash protection.
- **iPhone Time** — Ritual can ingest Apple Biome App.InFocus data where available and project it into daily iPhone Time metrics.
- **Location context** — Optional location pings can enrich habit logs and activity events, including bounded backfill for late signals.
- **Canonical read models** — Overview, Metrics, Logs, and Calendar now rely on backend-owned read models for more consistent totals across views.
- **Native desktop updater** — Desktop updates use the native Tauri updater flow with notarized macOS release artifacts.

### Improvements

- Faster and more stable manual logging updates.
- Cleaner Metrics app and habit lists.
- Better desktop release validation and updater artifact checks.

</Update>
