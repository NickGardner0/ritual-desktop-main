Ritual is a macOS desktop app built on top of a FastAPI backend, a Next.js dashboard, and a suite of passive data collectors. It captures what you do — automatically and manually — and gives you a single place to review and reflect on it.

## What's in the stack

Ritual is a full monorepo with several distinct apps working together:

| Layer | Tech |
|-------|------|
| Desktop shell | Tauri (Rust) — macOS native |
| Dashboard frontend | Next.js (TypeScript) |
| Backend API | FastAPI (Python) |
| Local database | SQLite (via Tauri) |
| Analytics pipeline | Tinybird |
| AI assistant | Gemini Flash 2.0 (primary) + OpenAI fallback |
| Search | Typesense |
| iOS companion | Swift — Apple Watch data bridge |
| Browser extension | Web extension for browser activity |

## Quick orientation

If you're new to Ritual, start here:

<Steps>
  <Step title="Download and install">
    Download the macOS desktop app. It installs a Tauri wrapper that runs the dashboard and starts the background watcher process.
  </Step>
  <Step title="Connect your integrations">
    Link Whoop via OAuth. The Apple Watch and computer tracking start automatically once the app is running.
  </Step>
  <Step title="Add your habits">
    Set up the habits you want to track. Some are auto-created from your integrations; others you define manually.
  </Step>
  <Step title="Start your daily review">
    Open the Index view each morning. Review yesterday, note today's intent, and let Ritual surface patterns over time.
  </Step>
</Steps>
