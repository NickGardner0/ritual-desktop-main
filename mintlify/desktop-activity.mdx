Ritual Desktop includes a local Mac watcher that turns computer activity into useful review data.

## What It Tracks

The watcher can capture:

- **Computer Time** — daily and all-time active computer usage.
- **Apps** — ranked app usage for the selected date range.
- **Websites** — domain-level browser activity when available.
- **Activity context** — recent computer usage that can help summaries explain how the day was spent.

This powers the Computer Time habit, Metrics app and website lists, Computer Time charts, and AI activity summaries.

## How It Works

<Steps>
  <Step title="Local capture">
    The watcher runs locally on your Mac and records foreground app and browser activity into a local activity database.
  </Step>
  <Step title="Sync and projection">
    Activity is synced into Ritual's backend and projected into daily metric facts for Computer Time.
  </Step>
  <Step title="Canonical display">
    Overview, Metrics, Logs, and Calendar read from backend-owned summaries so totals stay consistent across views.
  </Step>
</Steps>

## Permissions

Computer activity tracking requires macOS Accessibility permission. Ritual uses that permission to identify the active app/window and does not require screen recording for the current watcher path.

<Note>
  If local activity is available but backend sync is delayed, the desktop app can use a local fallback for activity-specific widgets. Backend habit totals remain the source of truth for final totals.
</Note>
