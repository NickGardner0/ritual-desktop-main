The Ritual dashboard is a Next.js app served inside the Tauri desktop shell. It's organized into five main views.

## Dashboard views

<CardGroup cols={2}>
  <Card title="Index" icon="house">
    Your daily overview. Shows today's habit completion, active wearable signals (Whoop recovery, Apple Watch activity), computer time summary, and your current momentum across key habits.
  </Card>
  <Card title="Logs" icon="list">
    A clean, chronological history of all your habit logs. Filter by habit, date range, or status (completed / skipped / missed). Quick-edit entries inline without leaving the view.
  </Card>
  <Card title="Calendar" icon="calendar">
    A calendar heatmap view that connects behavior to time patterns. See how your habits cluster around days of the week, and identify gaps at a glance.
  </Card>
  <Card title="Timer" icon="timer">
    Focused work session timer. Sessions automatically log to the appropriate habit (e.g. `code`, `study`) when they end — no separate logging step needed.
  </Card>
</CardGroup>

## AI Chat

The built-in chat assistant connects to Gemini Flash 2.0 and has full access to your habit history, computer activity, and wearable data.

<CardGroup cols={2}>
  <Card title="Plain-language queries" icon="message">
    Ask questions like *"how many times did I work out last month?"* or *"was my sleep better on days I didn't have caffeine?"* and get answers from your actual data.
  </Card>
  <Card title="Persistent conversations" icon="messages">
    Each conversation is saved and tied to your account. The assistant maintains context across sessions, so you can pick up where you left off.
  </Card>
</CardGroup>

## Habit system

Habits are the core primitive in Ritual. Each habit has:

| Field | Description |
|-------|-------------|
| `name` | The habit name (e.g. `run`, `meditation`, `sleep`) |
| `category` | Grouping for display (e.g. `fitness`, `wellness`, `focus`) |
| `icon` | Emoji or icon for visual scanning |
| `unit_type` | How it's measured: duration, count, boolean, amount |
| `sensor_type` | `Manual`, `Apple Watch`, `Whoop`, `Computer` |
| `integration_source` | `whoop`, `apple_health`, `oura`, `fitbit`, `garmin` — or null for manual |

### Smart synonym resolution

When you log a habit, Ritual resolves natural language variations to the canonical habit name. Built-in synonyms include:

- `run` → running, ran, jog, jogging, jogged
- `workout` → exercise, gym, training, work out
- `meditation` → meditate, mindfulness
- `water` → hydrate, hydration, drink
- `code` → coding, programming, develop

### Log statuses

Every habit log has a status: `completed`, `skipped`, or `missed`. This lets you distinguish between days you actively chose to skip a habit versus days you just forgot.

## Screenshot import

The screenshot analyzer uses Gemini Flash 2.0 (with OpenAI as fallback) to extract habit data from screenshots. Useful for:

- Importing Apple Screen Time weekly summaries
- Logging workouts from a fitness app screenshot
- Bulk-importing data from any visual source

Upload a screenshot → Gemini extracts the relevant habits and amounts → review and confirm → logged.

## Native widget

A native macOS widget for quick logging without opening the full dashboard. Log a habit, start a timer session, or check today's summary from the menubar.
