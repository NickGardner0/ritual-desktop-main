---

Ritual's context layer is now centered on structured activity and habit data rather than a separate recorder workflow.

The current system combines:

- Manual and voice habit logs
- Computer Time, app usage, and website usage from the Mac desktop watcher
- iPhone Time from Apple Biome App.InFocus data when available
- Wearable and health signals
- Optional location context for habit and activity events
