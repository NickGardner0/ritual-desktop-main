Ritual includes a persistent AI assistant that has access to your full tracking history. It's built for reflection and pattern analysis — not generic productivity advice.

## What the assistant can see

| Data source | What it has access to |
|---|---|
| Habit logs | Full history: habit name, date, status, duration, amount, notes |
| Computer activity | Daily app summaries, browser domain breakdowns, active vs. AFK time |
| Whoop data | Sleep duration, recovery score, daily strain — synced automatically |
| Apple Watch | Activity rings, workout sessions, heart rate |
| Weather | Daily conditions attached to every log entry |

## How to use it

The assistant works best with specific, data-grounded questions. Some examples:

```
"How consistent was I with workouts last month?"
"Was my recovery score better on days I slept more than 7 hours?"
"What were my top 3 apps by time last week?"
"On days I didn't have caffeine, how did my focus sessions go?"
"Summarize my habits for the past two weeks."
```

You can also use it for open-ended reflection:

```
"What patterns should I pay attention to?"
"What's changed about my routine in the last 30 days?"
```

## Under the hood

<CardGroup cols={2}>
  <Card title="Gemini Flash 2.0" icon="bolt">
    The primary model. Gemini Flash is ~3x faster than GPT-4o-mini for most queries and handles long context windows well — important for habit history that spans months.
  </Card>
  <Card title="OpenAI fallback" icon="rotate">
    If Gemini is unavailable, the assistant automatically falls back to an OpenAI model with no change in behavior from your perspective.
  </Card>
  <Card title="Persistent conversations" icon="messages">
    Conversations are stored per-user in the database. You can continue a conversation days later and the assistant retains context from earlier messages.
  </Card>
  <Card title="Screenshot analysis" icon="image">
    The same Gemini Flash model powers screenshot import — upload an image of a weekly report or workout summary and it extracts and logs the relevant habit data.
  </Card>
</CardGroup>

## Conversation management

Each conversation is a named thread stored in the backend. The API supports:

- Creating a new conversation
- Retrieving a conversation by ID (with full message history)
- Fetching the most recent conversation for the user
- Adding messages (both user and assistant roles) with optional tool payloads

The dashboard's Chat view always opens your most recent conversation, so you can pick up where you left off without any extra navigation.

## Tips for better results

<Tip>
  Be specific about time windows. "Last month" works, but "the week of February 10th" gives the assistant a clearer target and tends to produce more accurate answers.
</Tip>

<Tip>
  Ask follow-up questions. The assistant remembers your conversation history, so you can start broad ("summarize last month") and drill in ("what happened with sleep in that second week?").
</Tip>
